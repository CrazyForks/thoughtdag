# 完整功能索引

[English](/features) · [功能导航](/zh/guides/)

本页用于快速扫描当前产品功能区。具体操作由功能说明负责；[功能状态](/zh/reference/feature-status)区分当前能力与实验方向。

## 画布与导航

- 多画布的新建、重命名、切换、归档与删除；
- 无限画布：按住中键或右键平移、滚轮缩放、移动节点、框选节点；
- 三档语义缩放：完整卡片、收获句门牌、图标级标记；
- 小地图、缩放控件、分区导航、节点搜索、沿结构连线的方向键导航、根路径高亮；
- **一键排版**、局部**对齐**、分区框、批注显隐、撤销与重做。

说明：[画布、导航与分区](/zh/guides/canvas-projects)

## 对话节点与浮动侧栏

- 一个节点保存问题、回答版本、生成模型、角色、高亮与附件；
- 沿路径继续、从所选文字**探索**、编辑问题和回答、原地或以兄弟节点重新生成；
- 浮动侧栏集中提供阅读、版本切换、附件、高亮、汇入顺序、分组上下文树与追问输入；
- 节点右键菜单提供面板/阅读入口、重新生成、概括成便签、复制、CLI 接续、复制副本、归档和删除。

说明：[对话节点与侧栏](/zh/guides/conversations)

## 连线与模型可见上下文

- 紫色实线对话路径、橙色实线探索分支、紫色虚线摘要引用、红色虚线随动评审；
- **将发送**按材料、引用和对话显示下一次请求；
- 删除或转换连线而不删除节点；归档内容后保留在图上但退出上下文；
- 上下文指纹、陈旧标记、回答版本与按依赖顺序重放；
- 改变上下文后，用相同问题与模型重新生成，进行受控比较。

说明：[控制上下文](/zh/guides/context-control) · [版本、陈旧与重放](/zh/guides/versions-replay)

## 材料节点与阅读器

- 在当前[输入边界](/zh/reference/supported-inputs)内支持 PDF、图片、HTML、DOCX、Markdown、文本、代码和链接快照；
- 视材料提供原文、文本与导读视图，以及识别和可编辑提取文字；
- 从所选文字或图像区域提问，把段落或图片保存为独立节点，并保留页码来源；
- 阅读侧栏承载基于来源的问题链，并在来源、回答和画布节点之间跳转；
- 材料总览与继承附件的包含/排除控制。

说明：[材料节点与阅读器](/zh/guides/materials)

## 整理与评审

- **合并摘要**、**合并并删除**、**串联高光**，以及多种高亮下游传递方式；
- 把连续、无分叉的片段生成凝练副本，同时保留原路径和受保护的决策/转折节点；
- 随动评审节点、图结构诊断，以及手动或自动更新依赖结果。

说明：[合并、高亮与凝练](/zh/guides/organize)

## 模型、工具、角色与记忆

- 运行时服务商预设、OpenRouter 授权、Ollama、自定义兼容 endpoint、`.env` 服务商与受支持订阅；
- 全局模型选择和节点级模型钉选，每个回答版本记录生成模型；
- 网页搜索、学术搜索、视觉模型改道，以及本地/远程 MCP 工具；
- 节点角色的继承、设置与重置，以及可编辑角色库；
- 记忆即文档：偏好、身份两份文档随事实到来改写（带变更记录与撤销），每个主题一份从打标对话里写出的档案（是什么、定过的决定、现在到哪、还没解决；每句带来源），判不出主题的项目事实进待归档，其他 Agent 的记忆文件作只读来源；
- 提问时回忆：问题涉及的主题把档案整份带入；查细节的问题再按相关度补原话片段；每条列出并标价、可去掉；带入量三档（省、标准、多带）；
- 节点的相关对话：词与主题做 chips，模型扩展查询，卡片带看、引用；
- 判断模型（快思考）：一个开关，默认开；Jev 类 System One 接口可经聚合商、官方 API、Cloudflare Workers AI、自建服务接入，或由对话模型代答（未校准）；六秒超时、一分钟熔断，每个判断都有规则兜底；
- 主题：由人命名或模型提议的主题表；判断模型在宿主后台打标；命令行 `thoughtdag topics`。

说明：[记忆](/zh/guides/memory) · [模型、工具与记忆](/zh/guides/models-tools) · [连接模型](/zh/setup) · [判断模型](/zh/setup#decision-model)

## Agent 对话地图

- 按项目目录发现受支持的本地 Codex、Claude Code、DeepSeek Harness 与 Pi 会话；
- 建立独立图镜像，对话成为节点，tool result 保留为可检查附件，原 Agent 会话不受画布修改影响；
- 增量追加、只看变化、多会话挂入画布、重新镜像和来源状态提示；
- **接入**管理，以及可选的一键接入命令。

说明：[Agent 对话地图](/zh/guides/session-atlas)
