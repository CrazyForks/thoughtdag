# Start with the problem in your conversation

ThoughtDAG is an open-source AI conversation canvas. Nodes hold questions and answers; wires organize which conversation paths feed into the next question.

| What is getting in the way? | Try this |
| --- | --- |
| An unrelated discussion or old assumption keeps entering the next answer. | [Edit AI context while keeping past conversations](./edit-ai-context) |
| A side question interrupts the main thread. | [Branch a conversation and reconnect useful ideas](./branch-ai-conversations) |
| You remember a past conclusion, but not its original conditions. | [Find and cite earlier AI discussions](./reuse-past-ai-discussions) |

Each tutorial includes a short illustrated animation and steps to try in the app. The history tutorial requires the desktop app and supported local conversation records.
