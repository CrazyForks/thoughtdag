# 如何编辑 AI 的上下文，同时保留已经聊过的内容

当对话跑偏或某条思路不再适用时，你想沿另一条路继续，但又不想删掉之前的讨论，因为它们也许以后还有用。

ThoughtDAG 是开源 AI 对话画布。一轮问答是一个节点，连线组织后续问题可以沿用的对话。你可以保留节点，移除一条进入后续问题的路线，再检查上下文是否按预期变化。节点在画布上可见，不等于它已经进入模型输入。

## 先做一个容易看清的例子

准备已配置好模型的 ThoughtDAG。练习时先关闭输入区的“回忆”，不添加其他材料，便于看清这次连线改动。

1. 双击画布空白处，分别提出“为什么我收藏了文章，却很少回头读？”和“今晚吃什么？”。
2. 沿收藏问题继续追问：“总结我们聊了什么”。
3. 从晚饭节点的连接点拖线到总结节点，把它作为引用接入。
4. 重新生成总结。现在，两条路线汇入同一个节点。

交互示意：以阅读计划为例，先移除支线进入后续问题的连接，再把每天 30 分钟改为 15 分钟，重新生成计划。原支线仍然保留；移除连线不会自动改写已有回答。其他输入路径仍需核对。

## 1. 看清下一步会沿用什么

双击总结节点打开侧栏，点击追问框上方的“将发送 ~… tok · … 条消息”。查看材料、显式引用和对话轮次，确认晚饭这条路线出现在哪里。

预览帮助检查当前画布路径的组成，token 数是估算值。如果开启了“回忆”，发送时还可能加入检索到的历史，需要另行核对回忆条目。

## 2. 移除不想继续使用的路线

选中从“晚饭”节点进入“总结”节点的那条连线，执行删除。“晚饭”节点本身仍会留在画布上，你可以以后随时回看或重新连接它。删除一根线只移除了这一条路线。

再次检查连线和上下文预览。如果同样的内容还通过另一条路径、引用或附件进入了上下文，你也需要单独处理。另外，如果原有的“总结”回答本身已经复述了晚饭的内容，这些文字仍可能随“总结”节点的回答进入后续对话，所以你还需要重新生成或编辑这份总结。

## 3. 更新回答，再继续问

保持“总结”节点里的问题和所用模型不变，点击重新生成该节点的回答。通过版本切换功能比较重新生成前后的差异。确认没问题后，再从更新后的节点继续追问，例如：“给我一个每天十分钟的阅读安排。”

先检查上下文是否按预期改变，再看回答。相同问题重新生成也可能得到不同文字，单次变化不能证明回答质量提高。

原来的探索还在，你可以决定哪些内容继续参与新问题。处理研究中的旧假设、项目里放弃的方案，也可以用这个方法。
