# 从对话里遇到的问题开始

ThoughtDAG 是开源 AI 对话画布。节点保存一轮问答，连线组织哪些对话路径会进入下一个问题。

| 遇到了什么问题？ | 可以这样做 |
| --- | --- |
| 无关讨论或旧假设一直影响后面的回答。 | [编辑 AI 上下文，同时保留过去的讨论](./edit-ai-context) |
| 想追问一句话，又不想打断主线。 | [展开对话分支，再接回有用的思路](./branch-ai-conversations) |
| 记得过去的结论，却想不起当时的条件。 | [查找并引用过去的 AI 讨论](./reuse-past-ai-discussions) |

每篇教程都有简短的交互示意动画和可以在应用里操作的步骤。历史对话教程需要桌面版，以及已保存在本地、受支持的会话记录。

第一次使用？先[安装并连接模型](/zh/)。
